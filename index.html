Sobre

Um pouco da minha toca

lógica curiosidade

Formado em Análise e Desenvolvimento de Sistemas (2024), migrando de área com um objetivo claro: construir software que resolve problemas reais.

Gosto de entender o "porquê" por trás de cada decisão técnica — não só fazer funcionar, mas entender o que acontece por baixo do framework. Foi assim que aprendi Python e Flask: construindo o Gyro-manutenções, um sistema de gestão de frota para uma transportadora real, hoje pronto para implantação. Atualmente aplico essa mesma abordagem no aprendizado de Java e Spring Boot, minha próxima stack principal.

Busco minha primeira posição como desenvolvedor backend júnior, onde possa aprender com um time e seguir contribuindo com a mesma responsabilidade que tive construindo algo usado por uma empresa de verdade.
